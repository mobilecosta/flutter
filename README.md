## Curso FLUTTER EXPERIENCE · 10ª EDIÇÃO · 28 SET → 4 OUT

O app desta edição é um álbum de figurinhas digital. Não é app de exemplo, não é to-do list com dado falso no código:

• Login e cadastro de verdade — o backend responde, o token vai para o cofre do dispositivo, a sessão expira e o app devolve você para o login sozinho.

• Um servidor de verdade por trás — a API roda na sua máquina, sem Docker e sem banco para instalar. Você recebe pronta.

• 980 figurinhas numa lista que rola sem travar, com busca e filtro. É o tipo de tela que trava a maioria dos devs.

• 8 telas construídas, do flutter create vazio ao álbum completo — mais o arquivo do Figma com as 10 telas do produto, tokens e componentes.

• A arquitetura que o próprio time do Flutter documenta: MVVM em camadas, Command e Result, go_router, dio + retrofit, sessão no flutter_secure_storage. Sem versão simplificada "para curso".

Na sexta, esse app está rodando no seu celular, contra um servidor de verdade, com o código na sua máquina. É um projeto que segura entrevista — e que quem contrata não vê todo dia.
